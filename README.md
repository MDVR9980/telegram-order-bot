# telegram-order-bot

Telegram bot for automating custom art commissions and order management for **Linoria Art Studio**.

ربات فروش و مدیریت سفارش‌های **استودیو هنری لینوریا** — Python 3.11+ ، aiogram 3 ، SQLite.

## ✨ امکانات

### برای مشتری
| بخش | توضیح |
|---|---|
| 🎨 ثبت سفارش | ۴ مرحله با دکمه: نوع اثر ← تعداد افراد ← ارسال عکس‌ها ← توضیحات. نوار پیشرفت و دکمه «مرحله قبل» دارد. هر سفارش یک **شماره سفارش** اختصاصی می‌گیرد |
| 🧮 قیمت | قیمت را ادمین بعد از دیدن عکس‌ها تعیین می‌کند. مشتری فقط بازه قیمت (مثلاً ۲۵۰ تا ۵۰۰ هزار تومان) را می‌بیند |
| 💳 پرداخت | نمایش شماره کارت (با یک لمس کپی می‌شود) و ارسال عکس رسید. اگر مشتری عکس رسید را بدون زدن دکمه بفرستد، ربات می‌پرسد رسید کدام سفارش است |
| 🎟 کد تخفیف | وارد کردن کد تخفیف قبل از پرداخت |
| 🎁 دعوت دوستان | لینک دعوت اختصاصی؛ به ازای هر دوستی که اولین سفارشش را پرداخت کند، یک تخفیف (پیش‌فرض ۱۰٪) که روی سفارش بعدی خودکار اعمال می‌شود |
| 📦 سفارش‌های من | پیگیری **مرحله‌به‌مرحله** هر سفارش (✅ / 🔄 / ⚪️) همراه با جزئیات و قدم بعدی |
| 👀 پیش‌نمایش | تایید پیش‌نمایش یا درخواست اصلاح |
| 🎁 تحویل | فایل نهایی با کیفیت بالا و قابل چاپ، هر زمان قابل دریافت دوباره. فقط تحویل دیجیتال (ارسال پستی ندارد) |
| ⭐️ امتیاز، 💬 پشتیبانی، 📖 راهنما، 💰 تعرفه‌ها، 🖼 نمونه‌کارها | |

### برای ادمین (`/admin` یا دکمه «🛠 پنل مدیریت»)
- 🔔 **سفارش جدید** همراه با عکس‌های مشتری و دکمه‌های قیمت سریع (۲۵۰، ۳۰۰، ...، ۵۰۰ هزار) یا «✍️ مبلغ دلخواه»
- 🧾 **کارت کامل سفارش**: مشتری، سوابق خرید او، زمان‌ها، قیمت و تخفیف، تعداد فایل‌ها، و دکمه دیدن عکس‌ها، رسید، پیش‌نمایش‌ها و فایل‌های تحویلی
- 📋 لیست سفارش‌ها بر اساس وضعیت (منتظر قیمت، رسیدها، در حال انجام، ...، همه)، جستجو با شماره (`/order 12`)
- ✅ / ❌ تایید یا رد رسید، ✏️ تغییر قیمت قبل از پرداخت، 👀 ارسال پیش‌نمایش، 📤 تحویل فایل نهایی، 💬 پیام به مشتری، 🗑 لغو
- 🎟 **کدهای تخفیف**: ساخت کد درصدی یا مبلغ ثابت، با سقف تعداد استفاده و تاریخ انقضا؛ فعال/غیرفعال/حذف
- 🎨 **خدمات و قیمت‌ها** (بدون نیاز به ویرایش کد): بازه قیمت، دکمه‌های قیمت سریع، حداکثر تعداد عکس، افزودن/ویرایش/مخفی کردن نوع آثار و گزینه‌های تعداد افراد
- ⚙️ **تنظیمات**: شماره کارت، صاحب حساب، بانک، زمان آماده‌سازی، درصد تخفیف دعوت، شرط تخفیف دعوت، آیدی پشتیبانی، لینک کانال، متن خوش‌آمد
- 📊 آمار، 📣 پیام همگانی، 🟢/🔴 باز و بسته کردن پذیرش سفارش، 🚫 مسدود کردن (`/block`، `/unblock`)
- 👑 **سوپر ادمین** (آیدی در `.env`) می‌تواند ادمین اضافه یا حذف کند

### چرخه سفارش
```
🧮 تعیین قیمت (ادمین) → ⏳ پرداخت (مشتری) → 🔎 بررسی رسید → 🎨 طراحی → 👀 پیش‌نمایش → ✅ تحویل فایل نهایی
                              ↑   رد رسید   ↩︎                        ↕ اصلاح
```

### قوانین تخفیف
- روی هر سفارش **فقط یک تخفیف** اعمال می‌شود. اگر مشتری کد تخفیفی وارد کند که از تخفیف دعوتش بیشتر است، کد جایگزین می‌شود و تخفیف دعوت برای سفارش بعدی به حسابش برمی‌گردد.
- هر مشتری از هر کد تخفیف فقط **یک بار** می‌تواند استفاده کند.
- اگر سفارش لغو شود، تخفیف آن (چه دعوت، چه کد) آزاد می‌شود و برمی‌گردد.
- تخفیف دعوت دو حالت دارد که از تنظیمات قابل تغییر است:
  - **بعد از اولین خرید دوست** (پیش‌فرض): وقتی پرداخت اولین سفارش دوست تایید شود. امن‌تر است، چون با ساختن اکانت‌های جعلی نمی‌شود تخفیف گرفت.
  - **با عضویت دوست**: به محض اینکه دوست ربات را با لینک استارت کند.
- فقط کاربرانی که قبلاً عضو ربات نبوده‌اند به عنوان دعوت‌شده حساب می‌شوند.

## 🚀 نصب روی سرور (Ubuntu / Debian)

### ۱. ساخت ربات و گرفتن آیدی
1. در [@BotFather](https://t.me/BotFather) دستور `/newbot` را بزنید و **توکن** را بردارید.
2. آیدی عددی خودتان را از [@userinfobot](https://t.me/userinfobot) بگیرید.
3. **ربات خودتان را یک بار استارت کنید**، وگرنه ربات نمی‌تواند به شما پیام بدهد.

### ۲. روش پیشنهادی: Docker
```bash
curl -fsSL https://get.docker.com | sh
```
```bash
git clone https://github.com/MDVR9980/telegram-order-bot.git /opt/telegram-order-bot
```
```bash
cd /opt/telegram-order-bot && cp .env.example .env && nano .env
```
```bash
docker compose up -d --build
```
دیدن لاگ:
```bash
docker compose logs -f
```
آپدیت به نسخه جدید:
```bash
git pull && docker compose up -d --build
```

### ۳. روش جایگزین: بدون Docker (systemd)
```bash
apt install -y python3-venv git
```
```bash
git clone https://github.com/MDVR9980/telegram-order-bot.git /opt/telegram-order-bot
```
```bash
cd /opt/telegram-order-bot && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```
```bash
cp .env.example .env && nano .env
```
```bash
cp deploy/linoria-bot.service /etc/systemd/system/ && systemctl daemon-reload && systemctl enable --now linoria-bot
```
```bash
journalctl -u linoria-bot -f
```

### بکاپ
دیتابیس در `data/bot.db` است. اسکریپت `deploy/backup.sh` هر روز یک نسخه پشتیبان در `backups/` می‌سازد و نسخه‌های قدیمی‌تر از ۱۴ روز را پاک می‌کند (به `sqlite3` نیاز دارد). برای اجرای خودکار، آن را به cron اضافه کنید.

## ⚙️ تنظیمات

### فایل `.env`
| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن BotFather |
| `SUPER_ADMIN_ID` | آیدی عددی شما (سوپر ادمین) |
| `SUPPORT_USERNAME` | آیدی پشتیبانی، بدون @ |
| `CHANNEL_URL` | لینک کانال، برای دکمه نمونه‌کارها |
| `DB_PATH` | مسیر دیتابیس (پیش‌فرض `data/bot.db`) |
| `TIMEZONE` | منطقه زمانی برای نمایش تاریخ‌ها (پیش‌فرض `Asia/Tehran`) |

### تعرفه‌ها و تنظیمات داخل ربات
همه‌چیز از داخل ربات قابل تغییر است و نیازی به ویرایش فایل یا ری‌استارت نیست:
- **«🛠 پنل مدیریت» ← «🎨 خدمات و قیمت‌ها»**: بازه قیمت، دکمه‌های قیمت سریع، نوع آثار و تعداد افراد
- **«🛠 پنل مدیریت» ← «🎟 کدهای تخفیف»**
- **«🛠 پنل مدیریت» ← «⚙️ تنظیمات»**: کارت، متن خوش‌آمد، پشتیبانی، کانال، تخفیف دعوت و ...

فایل `catalog.json` فقط **یک بار، در اولین اجرا** برای مقداردهی اولیه خوانده می‌شود. بعد از آن، همه‌چیز در دیتابیس ذخیره می‌شود.

> برای حذف یک نوع اثر، آن را **مخفی** کنید تا سفارش‌های قبلی که آن را دارند درست نمایش داده شوند.

## 🗂 ساختار پروژه
```
bot/
  __main__.py        # راه‌اندازی، منوی دستورات، polling
  config.py          # خواندن .env
  db.py              # دیتابیس SQLite و وضعیت‌های سفارش
  catalog.py         # نوع آثار، تعداد افراد و بازه قیمت (قابل ویرایش از ربات)
  services.py        # منطق قیمت‌گذاری، تخفیف‌ها، رسید و دعوت دوستان
  storage.py         # ذخیره وضعیت گفتگوها در دیتابیس (با ری‌استارت پاک نمی‌شود)
  keyboards.py       # همه دکمه‌ها
  texts.py           # متن‌های خوش‌آمد، راهنما، تعرفه و پرداخت
  handlers/
    common.py        # /start، منو، راهنما، انصراف
    order.py         # مراحل ثبت سفارش
    user.py          # سفارش‌های من، رسید، پیش‌نمایش، امتیاز، پشتیبانی
    admin.py         # پنل مدیریت: سفارش‌ها، قیمت، رسید، تحویل، آمار، تنظیمات
    admin_manage.py  # کدهای تخفیف و مدیریت خدمات و قیمت‌ها
catalog.json         # مقادیر اولیه خدمات و قیمت‌ها (فقط در اولین اجرا)
deploy/              # سرویس systemd و اسکریپت بکاپ
```

## نکته‌ها
- ربات با **long polling** کار می‌کند و به دامنه، SSL یا پورت باز نیاز ندارد.
- فایل‌ها روی سرور ذخیره نمی‌شوند. ربات فقط `file_id` تلگرام را نگه می‌دارد و فایل‌ها روی سرورهای تلگرام می‌مانند.
- همه اطلاعات، از جمله اینکه هر کاربر در کدام مرحله است، در دیتابیس ذخیره می‌شود. پس با ری‌استارت یا آپدیت ربات چیزی از دست نمی‌رود.
