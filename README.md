# telegram-order-bot

Telegram bot for automating custom art commissions and order management for **Linoria Art Studio**.

ربات فروش و مدیریت سفارش‌های **استودیو هنری لینوریا** — Python 3.11+ ، aiogram 3 ، SQLite.

---

## ✨ امکانات

### برای مشتری
| بخش | توضیح |
|---|---|
| 🎨 ثبت سفارش | انتخاب مرحله‌به‌مرحله سبک، سایز، تعداد چهره و نوع تحویل با دکمه، همراه با نوار پیشرفت و دکمه «مرحله قبل» |
| 📸 ارسال عکس | ارسال چند عکس (آلبوم یا فایل)، توضیحات دلخواه، و در صورت تحویل پستی، شماره تماس و آدرس |
| 💰 محاسبه خودکار قیمت | قیمت نهایی قبل از تایید سفارش نمایش داده می‌شود |
| 💳 پرداخت | نمایش شماره کارت (با یک لمس کپی می‌شود) و ارسال عکس رسید |
| 👀 پیش‌نمایش | دریافت پیش‌نمایش، سپس تایید یا درخواست اصلاح با نوشتن توضیح |
| 🎁 تحویل | دریافت فایل نهایی در خود ربات؛ دانلود دوباره هر زمان از «سفارش‌های من» |
| ⭐️ امتیازدهی | امتیاز ۱ تا ۵ ستاره بعد از تحویل |
| 📦 سفارش‌های من | وضعیت لحظه‌ای هر سفارش و لغو سفارش‌های پرداخت‌نشده |
| 💬 پشتیبانی | پیام مستقیم به ادمین از داخل ربات، یا لینک به آیدی پشتیبانی |
| 📖 راهنما / 💰 تعرفه‌ها / 🖼 نمونه‌کارها | |

### برای ادمین (`/admin` یا دکمه «🛠 پنل مدیریت»)
- 🔔 اعلان خودکار سفارش جدید، رسید جدید، درخواست اصلاح و امتیاز مشتری
- ✅ / ❌ تایید یا رد رسید، با دلیل آماده یا دلیل دلخواه؛ مشتری می‌تواند رسید را دوباره بفرستد
- 👀 ارسال **پیش‌نمایش** و 📤 **فایل نهایی** برای مشتری (عکس یا فایل، چند فایل، همراه متن)
- 📋 لیست سفارش‌ها بر اساس وضعیت، با صفحه‌بندی؛ جستجو با شماره (`/order 12`)
- 💬 پیام به مشتری و پاسخ به پیام‌های پشتیبانی
- 📊 آمار: کاربران، سفارش‌ها، درآمد، میانگین امتیاز
- 📣 پیام همگانی (متن، عکس، ویدیو و ...)
- ⚙️ تغییر شماره کارت، نام صاحب حساب، بانک و زمان آماده‌سازی از داخل ربات
- 🟢 / 🔴 باز و بسته کردن پذیرش سفارش (برای وقتی سرتان شلوغ است)
- 🚫 مسدود کردن کاربر (`/block` و `/unblock`)
- 👑 **سوپر ادمین** (آیدی در `.env`) می‌تواند ادمین اضافه یا حذف کند

### چرخه وضعیت سفارش
```
⏳ در انتظار پرداخت → 🔎 بررسی رسید → 🎨 در حال طراحی → 👀 پیش‌نمایش ارسال شد
        ↑ (رد رسید)  ↩︎                                       ↓            ↓
                                                     ✏️ در حال اصلاح   👍 تایید
                                                                          ↓
                                                                  ✅ تحویل شده
```
ادمین می‌تواند در هر مرحله‌ای از «در حال طراحی» به بعد، مستقیم فایل نهایی را هم بفرستد.

## 🚀 نصب روی سرور (Ubuntu / Debian)

### ۱. ساخت ربات و گرفتن آیدی
1. در [@BotFather](https://t.me/BotFather) دستور `/newbot` را بزنید و **توکن** را بردارید.
2. آیدی عددی خودتان را از [@userinfobot](https://t.me/userinfobot) بگیرید.
3. **ربات خودتان را یک بار استارت کنید**، وگرنه ربات نمی‌تواند به شما پیام بدهد.

### ۲. روش پیشنهادی: Docker
```bash
curl -fsSL https://get.docker.com | sh
```
```bash
git clone https://github.com/MDVR9980/telegram-order-bot.git /opt/telegram-order-bot
```
```bash
cd /opt/telegram-order-bot && cp .env.example .env && nano .env
```
```bash
docker compose up -d --build
```
دیدن لاگ:
```bash
docker compose logs -f
```
آپدیت به نسخه جدید:
```bash
git pull && docker compose up -d --build
```

### ۳. روش جایگزین: بدون Docker (systemd)
```bash
apt install -y python3-venv git
```
```bash
git clone https://github.com/MDVR9980/telegram-order-bot.git /opt/telegram-order-bot
```
```bash
cd /opt/telegram-order-bot && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```
```bash
cp .env.example .env && nano .env
```
```bash
cp deploy/linoria-bot.service /etc/systemd/system/ && systemctl daemon-reload && systemctl enable --now linoria-bot
```
```bash
journalctl -u linoria-bot -f
```

### بکاپ
دیتابیس در `data/bot.db` است. اسکریپت `deploy/backup.sh` هر روز یک نسخه پشتیبان در `backups/` می‌سازد و نسخه‌های قدیمی‌تر از ۱۴ روز را پاک می‌کند (به `sqlite3` نیاز دارد). برای اجرای خودکار، آن را به cron اضافه کنید.

## ⚙️ تنظیمات

### فایل `.env`
| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن BotFather |
| `SUPER_ADMIN_ID` | آیدی عددی شما (سوپر ادمین) |
| `SUPPORT_USERNAME` | آیدی پشتیبانی، بدون @ |
| `CHANNEL_URL` | لینک کانال، برای دکمه نمونه‌کارها |
| `DB_PATH` | مسیر دیتابیس (پیش‌فرض `data/bot.db`) |
| `TIMEZONE` | منطقه زمانی برای نمایش تاریخ‌ها (پیش‌فرض `Asia/Tehran`) |

### تعرفه‌ها: `catalog.json`
سبک‌ها، سایزها، تعداد چهره، نوع تحویل و قیمت‌ها همه در این فایل هستند:

```
قیمت نهایی = قیمت سبک × ضریب سایز × ضریب تعداد چهره + هزینه نوع تحویل
```
بعد از ویرایش فایل، در ربات این مسیر را بزنید تا بدون ری‌استارت اعمال شود:
«⚙️ تنظیمات» ← «🔄 بارگذاری مجدد تعرفه‌ها»

> ⚠️ قیمت‌های فعلی فقط نمونه هستند. قبل از راه‌اندازی، آن‌ها را عوض کنید.
> شناسه (`id`) گزینه‌هایی را که قبلاً در سفارشی استفاده شده‌اند تغییر ندهید؛ فقط عنوان و قیمت را عوض کنید.

### تنظیمات داخل ربات
شماره کارت، نام صاحب حساب، نام بانک و زمان آماده‌سازی از «🛠 پنل مدیریت» ← «⚙️ تنظیمات» قابل تغییر هستند.

## 🗂 ساختار پروژه
```
bot/
  __main__.py        # راه‌اندازی، منوی دستورات، polling
  config.py          # خواندن .env
  db.py              # دیتابیس SQLite و وضعیت‌های سفارش
  catalog.py         # تعرفه‌ها و محاسبه قیمت
  keyboards.py       # همه دکمه‌ها
  texts.py           # متن‌های خوش‌آمد، راهنما، تعرفه و پرداخت
  handlers/
    common.py        # /start، منو، راهنما، انصراف
    order.py         # مراحل ثبت سفارش
    user.py          # سفارش‌های من، رسید، پیش‌نمایش، امتیاز، پشتیبانی
    admin.py         # پنل مدیریت
catalog.json         # تعرفه‌ها
deploy/              # سرویس systemd و اسکریپت بکاپ
```

## نکته‌ها
- ربات با **long polling** کار می‌کند و به دامنه، SSL یا پورت باز نیاز ندارد.
- فایل‌ها روی سرور ذخیره نمی‌شوند. ربات فقط `file_id` تلگرام را نگه می‌دارد و فایل‌ها روی سرورهای تلگرام می‌مانند.
- اگر ربات وسط یک مرحله (مثلاً وسط ثبت سفارش) ری‌استارت شود، کاربر باید آن مرحله را از اول شروع کند. سفارش‌های ثبت‌شده در دیتابیس محفوظ می‌مانند.
